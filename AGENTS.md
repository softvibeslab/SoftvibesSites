# Softvibes Sites — instrucciones para agentes

Este directorio es un workspace, no un único repositorio.

1. Consulta `index.html` para identificar el proyecto.
2. Entra únicamente al subproyecto solicitado.
3. Antes de editar, lee su README/AGENTS/CLAUDE/package.json y revisa `git status --short` si tiene Git.
4. No muevas ni renombres carpetas raíz; sus rutas pueden estar en uso.
5. No mezcles información entre clientes.
6. No edites dependencias, builds, ZIP ni repositorios externos salvo petición expresa.
7. Deja una verificación mínima para toda lógica no trivial.
8. No publiques, despliegues, hagas push/merge ni contactes terceros sin autorización explícita.

El catálogo operativo y las prioridades están en `PROMPT-TELEGRAM.md`.

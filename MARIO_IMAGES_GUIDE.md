## 🎨 Guía de Customización

### Si Quieres Cambiar Colores

**Hero (Naranja):**
```css
.hero-image svg linearGradient {
    stop 1: #f59e0b (cambiar aquí)
    stop 2: #d97706 (cambiar aquí)
}
```

**Proof (Rosa):**
```css
.proof-image svg linearGradient {
    stop 1: #f472b6 (cambiar aquí)
    stop 2: #ec4899 (cambiar aquí)
}
```

**Avatares:**
```css
.avatar-juan { background: linear-gradient(135deg, #3b82f6, #1e40af); }
.avatar-sofia { background: linear-gradient(135deg, #ec4899, #be185d); }
.avatar-carlos { background: linear-gradient(135deg, #10b981, #047857); }
```

### Si Quieres Reemplazar con Fotos Reales

**Hero (para foto de Mario):**
```html
<!-- Reemplazar SVG con: -->
<img src="mario-presentacion.jpg" alt="Mario Villanueva" class="hero-image">
```

**Proof (para foto del hotel):**
```html
<!-- Reemplazar SVG con: -->
<img src="casa-xtao.jpg" alt="Casa Xtao" class="proof-image">
```

**Avatares (para fotos reales):**
```html
<!-- Reemplazar: -->
<div class="avatar avatar-juan">JM</div>
<!-- Con: -->
<img src="juan-testimonial.jpg" alt="Juan M." class="avatar-testimonial">
```

Y agregar en CSS:
```css
.avatar-testimonial {
    width: 40px;
    height: 40px;
    border-radius: 50%;
    object-fit: cover;
}
```

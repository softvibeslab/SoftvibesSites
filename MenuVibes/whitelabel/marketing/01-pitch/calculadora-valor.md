# Calculadora de valor MenuVibes

## Objetivo

Ayudar al prospecto a comparar el costo de MenuVibes contra comisiones de apps,
tiempo perdido actualizando menus y oportunidades de reseñas/clientes
recurrentes.

## Formula principal: comisiones ahorradas

```text
Pedidos mensuales por apps x Ticket promedio x Comision promedio = Comision mensual
```

Ejemplo:

```text
120 pedidos x $220 x 25% = $6,600 al mes
```

Si MenuVibes recupera 20% de esos pedidos hacia WhatsApp:

```text
$6,600 x 20% = $1,320 de ahorro potencial mensual
```

## Formula secundaria: tiempo operativo

```text
Horas al mes corrigiendo/reenviando menu x Costo por hora = Costo operativo
```

Ejemplo:

```text
8 horas x $120 = $960 al mes
```

## Formula reputacion

```text
Visitas mensuales x % clientes satisfechos x % que salen a reseña = Oportunidad de reseñas
```

Ejemplo:

```text
600 visitas x 35% satisfechos activos x 15% salida a reseña = 31 oportunidades
```

Nota: nunca prometer reseñas positivas ni condicionar beneficios a opiniones
positivas. El beneficio debe ser por participar, responder NPS o registrar
visita.

# Secuencia de emails MenuVibes

Secuencia pensada para prospectos a quienes ya se les puede decir:

> "Te arme una demo de como podria verse tu menu digital."

## Orden recomendado

1. `email-01-primer-contacto.html` - enviar el mismo dia que se crea la demo.
2. `email-02-seguimiento.html` - enviar 2 dias despues si no responde.
3. `email-03-ultima-llamada.html` - enviar 5 a 7 dias despues.

## Asuntos sugeridos

- Email 1: `Te arme una demo de menu digital para {{negocio}}`
- Email 2: `Una idea rapida para vender mas desde tu QR`
- Email 3: `Cierro tu demo de MenuVibes?`

## Variables

Reemplazar:

- `{{negocio}}`
- `{{nombre_contacto}}`
- `{{demo_url}}`
- `{{whatsapp_url}}`
- `{{tu_nombre}}`

# Lead magnets MenuVibes

Materiales para abrir conversaciones con prospectos.

## Archivos

| Archivo | Uso |
|---|---|
| `guia-7-formas-menu-digital-vende-mas.md` | Version editable de la guia. |
| `guia-7-formas-menu-digital-vende-mas.pdf` | PDF final para enviar por WhatsApp/email. |
| `calculadora-comisiones.html` | Calculadora interactiva para mostrar ahorro vs apps. |
| `mini-auditoria-presencia-digital.md` | Plantilla para auditar prospectos y justificar la demo. |

## Secuencia recomendada

1. Mandar mini-auditoria personalizada.
2. Adjuntar la guia PDF si el prospecto aun no esta listo.
3. Usar la calculadora durante llamada o visita.
4. Cerrar con demo viva del menu.

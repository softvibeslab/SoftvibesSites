# Integraciones por cuenta del receptor

No se distribuyen configuraciones MCP activas, cookies, tokens ni permisos de esta máquina.
Conecta cada servicio desde la herramienta de tu agente y con credenciales propias.

| Necesidad | Opciones documentadas en el catálogo | Configuración |
|---|---|---|
| Investigación y referencias | browser, research, market-research | Búsqueda/navegador del agente |
| Diseño y recursos | ui-design, Figma, imagegen | Plugin/herramienta y derechos de los activos |
| Desarrollo | frontend/backend/fullstack, Astro, HTML | Runtime y dependencias del proyecto |
| Comprobaciones visuales | playwright, screenshot, a11y-audit | Navegador y dependencias declaradas |
| Repositorio | Git/GitHub | Cuenta con acceso al repositorio de destino |
| Publicación | habilidades del proveedor elegido | Hosting, dominio y autorización explícita |
| Documentación | Google Drive, Notion, documentos | Plugins originales y cuentas del receptor |

Para Envato: usa las fichas oficiales vigentes y verifica el tipo de paquete y licencia del
recurso elegido. Este paquete no contiene temas comerciales descargados ni una suscripción.
Para hosting: documenta destino, contenido que será reemplazado y modo de recuperación antes
de publicar. La instalación del ecosistema no despliega un sitio.

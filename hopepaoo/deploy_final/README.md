## 🎨 Customización

### Cambiar Colores Principales
Buscar `#ff385c` (rosa) en los HTML y reemplazar por tu color.

### Cambiar WhatsApp
En `landing.html`, línea ~430:
```html
<a href="https://wa.me/message/YOUR_WHATSAPP" class="btn btn-primary">
```

### Cambiar Email
En `landing.html`, línea ~433:
```html
<a href="mailto:tu_email@ejemplo.com" class="btn btn-secondary">
```

### Actualizar Foto
Reemplaza `profile.jpg` con nueva imagen (150x150 mínimo)

## 🔧 Troubleshooting

**"El CMS no guarda datos"**
→ Asegúrate de usar un navegador moderno (Chrome, Firefox, Safari)
→ Verifica que LocalStorage esté habilitado

**"La foto no se ve"**
→ Confirma que `profile.jpg` está en el directorio raíz
→ Usa ruta relativa: `<img src="../profile.jpg">`

**"Los links no funcionan"**
→ Reemplaza `YOUR_WHATSAPP` con número real (ej: `+5491234567890`)
→ Reemplaza emails de ejemplo

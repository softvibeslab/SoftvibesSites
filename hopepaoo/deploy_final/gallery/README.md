# 📸 Galería de Imágenes

Las imágenes deben ir en esta carpeta con los nombres:
- 01.jpg (Primera imagen)
- 02.jpg (Segunda imagen)
- 03.jpg (Tercera imagen)
- 04.jpg (Cuarta imagen)
- 05.jpg (Quinta imagen)

Tamaño recomendado: 400x500px (3:4 ratio)
Formato: JPG o PNG
Peso máximo por imagen: 200KB

La galería mostrará un modal al hacer clic en cualquier imagen.

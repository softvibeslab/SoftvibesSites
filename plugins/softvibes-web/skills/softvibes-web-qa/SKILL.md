# softvibes-web-qa

Lee el objetivo y el código. Identifica el flujo principal y compruébalo de principio a fin.
Ejecuta el build y las pruebas pertinentes. Comprueba móvil y escritorio, navegación por teclado,
foco, etiquetas, contraste, imágenes, rutas internas y metadatos. Revisa validación y destino del
formulario y estados de error. Si hay CMS verifica autenticación y autorización; no uses cuentas
ajenas. Busca contenido residual de la base reutilizada y credenciales en archivos públicos.
Registra comandos, resultados y límites. No presentes una lectura de código como prueba ejecutada.
No publiques como parte de la revisión sin una instrucción explícita.

# softvibes-web-workflow

Lee las instrucciones del proyecto y su estado Git. Recoge oferta, audiencia y conversión.
Aplica landing-inventory-first antes de diseñar: inventario real del receptor, comparación de nichos,
base existente autorizada o referencias Envato actuales. Si no tienes esa skill, realiza esos pasos
explícitamente y documenta la evidencia. No supongas acceso a los proyectos del autor del paquete.
Investiga fuentes, define copy y dirección visual. Elige stack según necesidad. Implementa en el
proyecto solicitado, prueba el recorrido de conversión y documenta la entrega. Usa otras skills
solo cuando sus herramientas estén disponibles. No copies datos de otros clientes, inventes hechos
ni publiques/contactes terceros sin autorización explícita. Diferencia realizado de propuesto.
